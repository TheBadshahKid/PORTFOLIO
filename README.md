# Elegant Storytelling Portfolio

A cinematic, immersive developer portfolio designed with a sophisticated storytelling narrative. Built with React and Framer Motion, this project blends professional technical showcasing with an elegant, magical aesthetic.

## ✨ Key Features

- **Prologue Entry**: A platform-based introduction sequence that transitions into the main experience.
- **Scroll-Based Storytelling**: Immersive "Chapter" transitions using `ScrollStage` presets for a cohesive narrative flow.
- **The Arsenal (Skills Map)**: A visually dynamic interactive map showcasing technical expertise and tools.
- **The Portfolio (Projects)**: A collection of high-impact projects documented with professional taglines and technical details.
- **The Milestones (Achievements)**: A curated timeline of growth, competitive programming ranks, and leadership roles.
- **Sorting Hat AI Chatbot**: A sophisticated companion that reveals insights about my skills and experience through natural conversation.
- **Procedural Ambient Sound**: A musical, HP-themed background score generated in real-time using the Web Audio API.
- **Hidden Easter Eggs**: Dispersed magical interactions (Lumos, Nox, Parseltongue, etc.) and a secret "Room of Requirement" for discovery.

## 🛠️ Technical Excellence

- **Code Splitting & Lazy Loading**: All below-fold sections and heavy components are lazy-loaded to ensure an instant first paint.
- **Performance Optimized**: Uses CSS containment (`contain`), `will-change` hints, and reduced GPU layers on mobile.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop experiences.
- **Refined Typography**: Elegant serif headings matched with clean, modern sans-serif body text for readability and style.
- **SEO Ready**: Professional metadata and structured semantic HTML.

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
